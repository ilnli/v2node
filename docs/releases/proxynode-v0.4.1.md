# Proxynode v0.4.1

修复启用审计时 GeoIP 加载占用过高，导致小内存主机升级或启动失败的问题。继承 v0.4.0 的 CN 目的地址拦截及实际出站 IP、国家和拒绝结果审计。

加载器逐条消费 CIDR、复用解析对象，并按文件大小一次分配读取缓冲，避免同时保留整份 protobuf 对象树和查询索引。国家查询仍使用 IPv4/IPv6 最长前缀匹配，保留未知国家、反向条目和损坏数据的处理规则。

使用发布包固定 GeoIP 数据（1,049,868 个国家网段）进行独立加载测试，峰值 RSS 从约 271 MiB 降至约 158 MiB；这是加载器测试值，不代表完整节点的总内存上限。旧加载器在 256 MiB、无 Swap 容器中被 OOM 杀掉。修复后的真实托管节点在启用审计、加载完整 GeoIP 数据的 320 MiB、无 Swap 容器中通过启动、重启、配置恢复及撤销测试。Go 全套测试通过，并补充字段乱序、未知字段、重复网段、反向标记及损坏 CIDR 回归测试。

面板托管主机更新时指定 `proxynode-v0.4.1`；独立安装执行：

```sh
sudo pnode update --version proxynode-v0.4.1
```

本补丁无需面板数据库迁移。已有 CN 拦截规则和审计设置继续生效；更新不会自动更改节点配置。发布流水线通过 Go 测试、竞态检测、托管生命周期及真实 Mihomo 互通验证后，生成 Linux amd64/arm64 安装包和校验文件。
